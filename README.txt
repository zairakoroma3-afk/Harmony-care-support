HOW TO PUT THIS ON VERCEL
1. Unzip this folder.
2. Put the files in a GitHub repository, OR use Vercel's project import flow.
3. In Vercel, create a New Project and import the repository.
4. Framework Preset: Other.
5. Root Directory: leave as the repository root.
6. Click Deploy.
7. After it deploys, go to Project Settings > Domains.
8. Add harmonycaresupportllc.com and follow Vercel's DNS instructions.

IMPORTANT
The contact form currently uses a placeholder mailto action.
